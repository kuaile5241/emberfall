# 元素职业、装备与战斗状态 · v0.3

三种职业由手中装备决定。开局拥有火、雷、水三把基础武器，可以选择初始职业；本轮拾取的高级武器进入装备列表，随后自由切换。换装保留生命、等级、祝福与当前攻击冷却，不把装备加成写入基础属性。

## 六件装备

| 元素 / 职业 | 基础武器 | 高级武器 | 实际技能差异 |
| --- | --- | --- | --- |
| 火 / 火焰骑士 | 余烬长剑 | 烬王重剑 | 长剑爆发后留下 3.2 秒火场，获得 5 秒增伤 20%；重剑火场更宽，持续 4.5 秒，获得 6 秒增伤 25%，普通重斩较慢、范围更宽 |
| 雷 / 雷刃游侠 | 引雷长枪 | 风暴战戟 | 长枪震击周身，最多再连锁 3 名目标并短暂眩晕，4 秒攻速 +30%；战戟最多连锁 5 名目标，0.65 秒后再震击一次，5 秒攻速 +35% |
| 水 / 潮汐使 | 涌泉法杖 | 深潮权杖 | 法杖水波减速 42%，留下 2.5 秒水域并获得 6 秒护盾；权杖减速 52%，3.6 秒水域每 0.8 秒造成额外伤害，护盾更厚、持续 7 秒 |

按 `Tab` 依次切换火 → 雷 → 水，优先使用对应元素已拥有的高级装备。同元素的基础和高级武器可在装备面板中选择。首区领取房间祝福时，保证获得当前元素的高级武器；之后每名精英优先掉落一件尚未拥有的高级武器，已有待拾取同款时不会再重复掉落。拾取不会自动替换手中武器。

普通攻击使用原有方向扇形与暴击规则。连续攻击形成三段连击，第三段伤害 +15%；超过 1.6 秒未攻击或更换武器后重置连击段数。攻击事件的 `duration` 是当前装备、祝福与攻速状态计算后的真实攻击间隔，动画可以据此同步。

## BUFF、冷却与伤害规则

- `余火昂扬` 同时提升后续普通攻击与技能爆发伤害。已经落地的火场按施放时伤害结算，不随换装或后续 BUFF 改写。
- `疾电` 减少后续攻击间隔。不会追溯清空已经开始的攻击冷却。
- `潮汐护盾` 是有限的吸收量：基础盾为 `30 + 最大生命 × 8%`，高级盾为 `48 + 最大生命 × 8%`。先计算护甲减伤，再扣护盾，溢出部分扣生命。完全由护盾吸收的一击不会给角色增加无敌帧；连续攻击仍会继续消耗护盾。
- 同名 BUFF 刷新持续时间和效果，不增加层数；护盾刷新替换吸收池，不叠加两份护盾。不同元素状态可以同时存在，支持换装组合使用。
- 技能冷却按火、雷、水分别记录。切换到同元素另一把武器不能清空冷却；未装备元素的计时仍继续。切换到尚未使用的元素，可以使用其技能。
- 升级祝福继续修改基础属性。最终数值由基础属性 × 装备修饰 × 临时 BUFF 计算，重复换装不会累积加成。原 `烈焰回响` 改名为 `元素回响`，其技能伤害与冷却加成适用于全部元素。
- 水减速影响敌人的真实移动速度；首领减速效果降低，眩晕最多 0.16 秒。
- 瞬时范围伤害、每次连锁、地面持续伤害均检查地形遮挡。技能清除飞弹也只作用于墙体同一侧。燃烧击杀走正常击杀、掉落、经验及击杀回血流程。
- 死亡清除地面技能、BUFF、护盾及技能计时；重新开始恢复为三把基础武器。本轮装备暂不跨局保存。

## 引擎接口

共享内容位于 `src/content.js`：

- `EQUIPMENT`：六个冻结配置对象，含 `id/name/type/className/element/tier/starter/description/skillName/skillDescription/variant/stats/skill`。
- `STARTER_WEAPON_IDS`：三把基础武器的 ID。
- `ELEMENTS`：以 `fire/lightning/water` 为键，包含 `id/name/className/color/buffName`。
- `equipmentById(id)`：未知 ID 返回 `null`。

游戏 API：

| 接口 | 内容 |
| --- | --- |
| `new Game({seed,difficulty,weaponId})` / `reset(...)` | 选择初始基础武器；无效或未解锁高级初始 ID 回退为火系基础武器 |
| `game.weapon` | 当前装备配置对象 |
| `game.inventory` | 当前已拥有装备 ID 数组 |
| `game.equipWeapon(id)` | 成功返回 `true`；拒绝未知、未拥有装备，以及死亡/结算状态换装 |
| `game.cycleWeapon()` | 切到下一元素，优先该元素最高等级装备 |
| `game.combatStats` | 当前实际伤害、攻速间隔、攻击范围、技能伤害/范围/冷却、速度、护甲、暴击率 |
| `game.statsForWeapon(id)` | 用相同基础属性和当前 BUFF 计算指定装备的实际数值；供面板比较 |
| `game.skillCooldowns` | `{fire,lightning,water}` 剩余冷却秒数 |
| `game.player.skillCd` | 当前装备元素冷却的兼容读写入口 |
| `game.player.shield` | 当前剩余护盾吸收量 |
| `game.activeBuffs` | `{id,name,element,duration,remaining,power,stacks:1}` 数组 |
| `game.areas` | `{id,element,weaponId,variant,x,z,radius,duration,remaining,...}` 地面区域数组 |
| 敌人状态 | `stun`、`slowRemaining`、`slowFactor`、`burnRemaining` |

新增/扩充事件：

- `attack`：保留坐标、朝向、范围、扇形角度，增加 `element/weaponId/variant/combo/duration`。
- `skill`：增加 `element/weaponId/variant/duration/targets/chain`。`targets` 含所有实际命中目标的 `{id,x,z}`；`chain` 每段为 `{from:{x,z},to:{id,x,z}}`。`duration` 是地面效果持续时间，不是施法动作锁定时间。
- `areapulse`：地面伤害脉冲的 `id/element/variant/x/z/radius`。
- `buff`：`action` 为 `apply/refresh/expire`，并带 BUFF 字段。
- `shield`：`{absorbed,remaining,x,z}`。
- `equip`：`{weaponId,previousWeaponId,element,name,className}`。
- `equipment`：获得装备，`{weaponId,name,element,tier,source}`；`source` 为 `drop/room`。
- `pickup`：装备拾取时额外包含 `weaponId`。

## 当前验证

`npm test` 共 **33 项通过**：保留原 16 项；新增 14 项元素、装备、BUFF 和状态测试；新增 3 项正常属性完整流程测试。

新增测试证明：切装不污染基础数值或清空冷却；火场确实持续伤害和结算击杀；雷链命中不同目标；水减速影响真实移动距离；护盾吸收、溢出、耗尽与过期生效；同名 BUFF 只刷新；高级雷/水确实造成延迟伤害；技能与连锁不能穿过转角墙体；首区和精英能可靠产出高级装备；死亡与重开状态正确。

正常属性测试固定种子 `913`，通过输入机器人走完六区，不改角色生命、伤害、移动速度或敌人数。各轮只使用单一元素及其实际获得的高级武器：

| 初始武器 | 结果 | 有效模拟时间 | 击杀 |
| --- | --- | --- | --- |
| 余烬长剑 | 通关 | 约 197 秒 | 70 |
| 引雷长枪 | 通关 | 约 192 秒 | 70 |
| 涌泉法杖 | 通关 | 约 233 秒 | 70 |

机器人精确读取敌人坐标与预警，并即时选祝福、喝药和闪避；此结果只说明三元素在该种子与策略下能以正常属性完成流程，不等于真人难度已经定稿。水系本轮未损失生命，说明精确走位与护盾组合很强，后续应根据真人试玩评估其防御强度。这里未宣称完成多种子难度评估、手柄/移动端验收或多人测试。

浏览器技能特效、骨骼动作、装备面板和操作验收由渲染/UI 整合后独立确认；引擎测试通过不代替这些验收。
