# AOE 与 BD 构筑调研：v0.8

调研日期：2026-10-02（Asia/Shanghai）。用途：为 Emberfall 的技能形态、装备组合和天赋提供原创设计依据。本页是研究与设计建议，实现范围及验证结果以 README 和版本验收文档为准。

结论：玩家应当能通过装备和天赋改变“技能怎么命中、什么时候命中、怎样衔接下一招”，而不仅是把同一个圆形区域放大、换色、加伤害。首个迭代适合先做暴雪、地下火柱、连锁雷与方向雷等能直接辨认的形态，再用少量明确的关键装备和有取舍的天赋组成 BD。

## 推断：适合 Emberfall 的原创方案

### 先改变命中方式

| 原创方向 | 玩家看到与操作的区别 | 战术用途 | 至少一种规则取舍 |
| --- | --- | --- | --- |
| 暴雪 | 在选定位置维持风雪；分批落冰，命中累积寒冷；冻结后可触发一次碎冰 | 拉怪、控场、铺设持续伤害；敌人离开后不应被全屏持续命中 | 更长持续时间，或更快冻结与更短覆盖；避免两者同时无代价叠满 |
| 地下火柱 | 沿瞄准方向或敌人附近分次出现裂纹、隆起、喷火；每根柱只伤害自身附近 | 清理长廊、切断怪群、预判移动 | 密集集中爆发，或更远分散覆盖；落点数量与单柱强度互相制约 |
| 连锁雷 | 命中首个目标后在有间距限制的敌人间跳跃；每次有可见连接 | 密集群怪、湿润状态联动 | 更多跳跃与较低后续伤害，或较少跳跃与更强首击 |
| 方向雷 | 沿瞄准方向穿透一条窄走廊，可由装备变为有限分叉 | 对齐敌人、击穿前排；瞄准价值高 | 更宽覆盖或更远穿透；偏离方向的敌人不应被同心圆补伤 |

形态的伤害判定应对应视觉落点和时序。火柱有延迟才会伤害，暴雪是持续脉冲，链雷有独立目标与跳跃上限，方向雷使用线段/宽度判定。墙体、房间边界和暂停状态必须参与判定，不能只画一种效果而继续复用全域圆形伤害。

### 让装备与天赋形成组合

先保留武器作为职业入口，添加数量受控的辅助装备/符印。每件关键装备明确写“改变了什么”，并且在同一职业内提供至少两种搭配。

- 暴雪型：延长风雪覆盖的装备与快速冻结天赋组成控场 BD；碎冰触发装备与集中落冰天赋组成爆发 BD。
- 火柱型：扩大柱间距的装备适合直线清怪；收拢落点的装备适合对单。天赋可以选择额外柱或提升单柱威力。
- 雷型：增加跳跃的辅助装备配合湿润状态形成群怪连锁；缩减跳跃、提升方向穿透的组合用于精确突破。
- 防御选择参与搭配：冷却、屏障或位移收益占用装备/天赋预算；输出最大化应有成本。

天赋可以先做少量有前置关系的分支和一个受预算限制的核心选择。营地允许自由试配，出征时保存不可变的本次配置，界面同步展示形态、关键效果、点数和组合来源。天赋与装备的加成先统一计算，再交给战斗；不要在 UI 和伤害逻辑里各维护一套规则。

### 验收必须验证“玩法变了”

1. 同职业换关键装备后，落点、跳跃、持续时间或方向命中至少一项变化；模型、装备栏、说明与战斗使用相同配置。
2. 未装备、换装、洗点、重新加载和再次出征，都不能残留旧构筑效果；出征中的修改只能影响下次配置。
3. 火柱延迟与单柱覆盖、暴雪持续脉冲、链雷目标去重、方向雷外侧不命中，分别有可控战斗测试。
4. 二次触发设明确来源、上限和排除条件：一次碎冰不递归生成自身，一条链雷不在同一跳重击同目标，状态叠层有上限，Boss 的控制收益有规则。
5. 营地试配 → 出征 → 祝福选择 → 两章结算 → 返回营地 → 重载的中英文流程通过；存档迁移不损坏既有装备与主线。
6. 浏览器截图/录像覆盖真实技能外观。模拟战斗通过只证明逻辑与流程；真人爽感、不同配置强弱和设备性能需另做试玩验收。

以上为设计建议，具体物品名称、天赋数、倍率和解锁方式由本轮实现与验收文档确认。

## 仍未确认

- 当前 Diablo IV、PoE 和 Last Epoch 赛季的最优 BD、完整实时节点和职业平衡，本次没有进行 meta 调研。
- 本项目各 BD 的真人操作难度、爽感和长期重复游玩价值，需要真实试玩数据。
- 大量持续区域、柱体与链雷同时出现时，在不同设备上的帧率上限，需要性能采样。
