# 连续墓城 · v0.2

本次将六块独立战斗场地改为同一张连续地图。可行走地形的包围盒为 **136 × 121 米**；包含岩壁、虚空边缘与小地图留白的世界范围为 **148 × 133 米**。面积为不规则矩形的并集，不能将包围盒面积当作实际可走面积。各主要区域约 30–40 米宽，比旧版 24 × 20 米的单室战斗场地更大。

## 路线与空间关系

城门前庭 → 转折墓道 → 无声回廊 → 圣堂通道 → 遗忘圣所 → 运钟石桥 → 熔火工坊 → 山腹长阶 → 钟下祭坛。

墓城按城门、墓室、礼拜空间、铸钟生产区与钟楼地宫的关系连接。路线先向东深入山体，再向北、向西绕回钟楼下方。入口旁有荒废墓园，圣堂与工坊之间有铸钟废仓；这两处可以步行探索，暂不加入额外奖励与任务系统。

清完当前区域后，按 `E` 领取三选一祝福，出口封印解除。玩家沿真实走廊移动，进入下一处区域时触发战斗；没有传送、重建地图或将角色重置到固定出生点。已经清除的区域保持可进入，回头不会刷新战斗。最终击败首领和全部随从后仍进入结算界面。

## 数据与渲染接口

`src/world.js` 是地图与碰撞的共同来源，`src/game.js` 的 `ROOMS` 保留为 `ZONES` 的兼容别名。

| 导出 | 用途 |
| --- | --- |
| `WORLD.bounds` | 世界装饰与小地图范围，字段 `minX/maxX/minZ/maxZ` |
| `ZONES` / `WORLD.zones` | 六处主区域：`id/name/theme/waves/center/bounds/entry/exit` |
| `WORLD.corridors` | 通道：`id/from/to/width/path/rects`，`from/to` 是区域索引 |
| `WORLD.alcoves` | 两处探索空间：`id/name/zoneIndex/center/bounds/path` |
| `WORLD.walkable` | 可行走矩形列表，四个边界字段直接位于对象上 |
| `WORLD.boundaries` | 矩形并集的外边缘，`x1/z1/x2/z2/normal`；不含内部地板接缝 |
| `WORLD.spawn` | 初始位置 `{x:0,z:10}` |
| `isWalkable(x,z,radius,rectangles?)` | 检查圆形碰撞体能否完整放入地形并集 |
| `constrainMove(fromX,fromZ,toX,toZ,radius,rectangles?)` | 分段扫掠与贴墙滑动 |
| `canTravel(fromX,fromZ,toX,toZ,radius,rectangles?)` | 路径上的地形/墙体遮挡检查 |
| `navigationTarget(from,target,radius,rectangles?)` | 用于追击和路标的可达导航点 |
| `unlockedSurfaces(index,rewardTaken)` | 当前进度下已开放地形 |

所有坐标均为米，以 X/Z 平面表示。角色、敌人、掉落、飞弹、攻击预警、出口与奖励宝箱都使用全局坐标。摄像机和环境不应在 `room` 事件时回到原点。

游戏状态新增：

- `visitedZoneIds` / `clearedZoneIds`：保存本轮已进入、已清除的区域 ID。
- `currentZoneId`：角色当前所在主区域的 ID；走廊返回 `null`。
- `nextWaypoint`：`{x,z,label,kind}`，`kind` 为 `fight/reward/travel/victory`。
- `objective`：简短的当前行动提示。
- `exit`：当前战斗区域的全局出口位置。

`roomIndex` 仍表示最新触发的战斗区域，不随回头移动减少。它与 `currentZoneId` 的含义不同。`interact()` 只负责奖励；向下一处区域推进由实际移动触发。

## 碰撞与追击

碰撞采用同一份地板矩形并集的真实外边缘。圆形角色可以跨越走廊与墓室的接合处，不会被内部矩形边界卡住。移动按最多 0.2 米的子步进行检查，闪避不能从墙的一侧跳到另一侧；斜向撞墙保留沿墙方向的移动。

敌人使用同一碰撞边缘，并通过区域中心与通道拐点组成的导航图绕行。普通攻击、范围伤害和敌方攻击检查墙体遮挡；飞弹检查整段运动路径，不能跨过拐角里的岩石空隙。未领取当前区域奖励前，下一条主通道不进入可行走集合。已清区域与旧通道始终保留。

## 验证范围

`npm test` 当前 16 项通过。原有 12 项战斗、升级、首领与重开测试保留，并改写流程测试让角色按每条通道实际步行推进。新增范围包括：

- 六区主路线和两处支路连通，首领体型可通过主通道。
- 远距离位移不能跨过转角岩石空隙，贴墙滑动可用。
- 未清除区域的出口封印阻止普通移动与闪避穿越。
- 飞弹被地形阻挡，敌人追击选择可达的通道转角。
- 完整通关流程中回到已清前庭，再步行返回当前区域，不重复触发旧战斗。

流程测试提高攻击力以缩短验证时间；它证明移动、战斗状态与通关逻辑可达，不代表真人手感、最终美术效果或跨设备性能已经通过验收。浏览器画面与操作验收由主项目整合后执行。

地图扩大后，敌人出生位置、接敌距离与逃跑空间均已改变。旧版小房间的正常属性通关记录不能用来证明本版难度；本次逻辑测试没有完成一轮真人正常属性通关，实际清场时长、远程敌人的压迫感与三档难度仍需在新版地图上试玩调整。当前保留原有战斗数值，未用“地图更大”推断难度已经更合理。

导航图覆盖主区域、通道拐点及支路，已经验证追击者能实际绕过一处转角到达玩家；测试未穷举所有体型、拥挤组合与地图位置。碰撞目前包含地形边界和区域封印，场景中的桌椅、炉座、棺木等装饰尚无独立碰撞体，因此必须在美术布置时让出可行走主线；它们不能作为战斗掩体使用。
