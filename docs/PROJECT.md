# 余烬地牢：钟下墓城 · v0.4

这是一个可从头打到结局的单人 3D 动作肉鸽章节，包含连续探索、战斗、成长、六区推进与最终 Boss。它是小体量独立游戏的可玩初版，尚未达到商业 ARPG 的内容量、动画精度或装备系统规模。

v0.4 在三元素战斗与六区连续地下城上加入可保存的营地：选装备、买补给、接委托、升级营地，再将战利品带回。两处支路现在有可领取的一次性奖励；怪群规模、范围技能反馈与祝福卡也已调整。职业仍由当前装备决定，开局选择不会把玩家锁定在一个职业。它是一张有分区推进和支路的连续地图，并非完整开放世界。

游戏使用 Three.js 与独立 JavaScript 战斗引擎，本地浏览器运行，无需账号或在线服务。建议电脑键鼠游玩。角色素材沿用 KayKit 的卡通比例，石材 PBR 贴图来自 Poly Haven；第三方 CC0 素材不属于项目原创模型，也不是写实人物。

**版本记录：** v0.1 建立首个可玩章节；v0.2 加入连续地图并替换角色和环境素材；v0.3 加入三元素、六武器与分层动画；v0.4 加入营地循环、支路奖励和怪群战斗。v0.3 的 33 项战斗/流程测试、22 项真实 GLB 动作检查及浏览器验收保留为历史证据。本轮测试范围见本文后段，最终构建与浏览器验收以 [ACCEPTANCE.md](ACCEPTANCE.md) 为准。

## 开始试玩

打开工程文件夹，双击 **`开始游戏.command`**。它会启动只监听 `127.0.0.1` 的本地静态服务，并在默认浏览器中打开 `http://127.0.0.1:4173/`。在营地选择火焰骑士、雷刃游侠或潮汐使，按需整备补给、接受委托，再点击“出征”；首次可选择“轻松”难度。

终端窗口需要在游玩期间保持开启；关闭该窗口或按 `Ctrl+C` 会停止服务。若本机端口被其他程序占用，启动器会说明原因，不会终止其他程序。如果系统未直接运行 `.command`，可在终端进入项目目录后执行：

```sh
./开始游戏.command
```

启动器读取 `dist/` 中的构建结果。若提示缺少构建，或者需要修改源代码，使用下列开发命令：

```sh
cd emberfall
npm ci
npm run dev
```

开发地址同样为 `http://127.0.0.1:4173/`。修改完毕后生成可供启动器读取的版本：

```sh
npm run build
```

`npm run preview` 可以预览构建结果；它和开发服务器、双击启动器使用同一端口，运行前关闭已有的对应本地服务。游戏的构建版运行依赖 Python 3；修改和重新构建还需要 Node.js/npm。依赖已经准备好的情况下，构建版游玩不需要联网。

## 怎么玩

| 操作 | 按键 |
| --- | --- |
| 移动 | `W A S D` |
| 瞄准 | 鼠标指向地面 |
| 普通攻击 | 按住鼠标左键或 `J`，也可单击 |
| 闪避 | `Space`，优先朝移动方向，未移动时朝瞄准方向 |
| 当前武器范围技能 | 鼠标右键或 `K` |
| 喝药 | `Q` |
| 清场领奖、支路互动 | `E` |
| 选择祝福 | 点击选项，或按 `1 / 2 / 3` |
| 装备与构筑 | `B` |
| 切换元素武器 | `Tab`，依次火 → 雷 → 水，优先该元素已拥有的高级装备 |
| 暂停、返回 | `Esc` |

红色地面预警标明即将落下的攻击。闪避带短暂无敌。范围技能会清除同一侧墙体内的附近飞弹，并对普通敌人产生短暂打断；具体效果取决于装备。药水有数量限制，满血时不会消耗。

经验、金币与装备靠近后自动拾取。清空当前区域会恢复一部分生命，按 `E` 领取三选一祝福后解除通道封印，再沿金色路标步行进入下一区域。`E` 不传送角色。最后必须击败丧钟守卫及全部随从才算通关。

经验升级先记账，当前波清空后再展示祝福，避免清群中途被弹窗截断。选择祝福、打开装备或暂停面板时，战斗计时暂停。切换到其他窗口会自动暂停。死亡、通关或主动撤退后结算营地收益，再次出征会开始新的一局；敌人配置、掉落与祝福选项随种子变化。

## 营地与跨局成长

首页包含四页，左侧角色预览随已选武器变化：

| 页面 | 实际功能 |
| --- | --- |
| 营地 | 查看出征地点、当前委托和携带补给，选择难度并出征 |
| 军械 | 选择已解锁的出征武器；未解锁装备可跳转对应委托 |
| 行囊 | 用金币购买、装入或取下补给，并支付金币/精华强化营地 |
| 委托 | 接受、改接委托，查看累计进度，完成后领取一次报酬 |

新营地有 120 金币、三把基础武器。每次可携带一件补给：烈刃药剂 45 金币，本局普攻与技能伤害提高 12%；守护符 35 金币，入场获得 35 点可消耗护盾。购买进入库存，选择携带后只在成功开始出征时扣一份。守护符不会随换装恢复，水系护盾刷新或结束也不会抹掉尚未用完的守护符护盾。

营地有三次永久强化，升级后的累计效果分别为生命 +10/+20/+30、伤害 +3%/+6%/+9%；费用依次为 120 金币、220 金币加 2 精华、380 金币加 4 精华。它们会实际进入下局属性，重复换装不会叠加。

四份委托分别要求累计击败 60 名敌人、3 名精英、完成 2 次支路目标、击败 1 次丧钟守卫。一次累计一份，出征前接受后才开始计算；改接保留已有进度。前面三份分别奖励烬王重剑、风暴战戟、深潮权杖，四份均有金币与精华。完成后需在委托页领取，重复点击不会再发奖。

| 出征结果 | 带回本局金币 | 精华 | 已实际拾得的装备、已接委托进度 |
| --- | --- | --- | --- |
| 通关 | 100%，另奖 80 金币 | 每 2 名精英 1 点，另奖 2 点 | 保留 |
| 阵亡 | 60% | 每 2 名精英 1 点 | 保留 |
| 主动撤退 | 25% | 0 | 保留 |

金币按比例向下取整；精英统计包含 Boss。营地钱包和战斗中的本局金币是两份数值，只有成功结算后才入账。结束同一局或领取同一委托均有重复保护。武器一旦入库，之后可从营地选择；本局未拾取的地面装备不计入收入。

## 职业、装备与组合

每局开始即拥有三把基础武器，以及已永久解锁的高级武器。`B` 面板显示全部六件装备、已拥有状态和实际属性；高级装备不会在取得后自动装备。

| 职业 | 基础武器 | 高级武器 | 主要玩法 |
| --- | --- | --- | --- |
| 火焰骑士 | 余烬长剑 | 烬王重剑 | 爆发后留下持续火场，获得短时增伤；重剑攻击更慢、伤害与范围更高 |
| 雷刃游侠 | 引雷长枪 | 风暴战戟 | 周身震击和连锁雷击，获得短时攻速；战戟连锁更多目标，并追加一次延迟雷震 |
| 潮汐使 | 涌泉法杖 | 深潮权杖 | 范围水波减速与有限护盾；权杖水域持续造成额外伤害、减速和护盾更强 |

三类普通攻击目前都使用近身方向判定，潮汐使的普通攻击不是远程法术弹。连续攻击的第三段伤害提高 15%；停止攻击超过 1.6 秒或更换武器会重置连击。

首区领取清场祝福时，保证获得**领取时所持元素**的高级武器。精英优先掉落尚未拥有的高级装备；同款已有待拾取掉落时不重复生成。六件全部取得后，不会继续重复掉落高级武器。武器没有随机词条，当前也没有护甲槽位、物品整理或交易系统。

不同元素的增益可同时存在：例如先施放水技能取得护盾，再换火武器获得增伤，再换雷武器取得攻速。各增益按原有剩余时间结束；同名增益只刷新，不叠层。护盾是有限吸收量，受击会消耗，刷新会替换旧护盾池，不会累加两份护盾。

技能冷却按火、雷、水独立记录，未装备元素也继续计时。切换同元素的基础和高级武器不能清空冷却。换装保留生命、等级、祝福和已有攻击冷却；面板数值包含装备、祝福与当前临时增益，反复换装不会累积加成。底部徽章随装备变更，生命条旁显示护盾与增益倒计时。

本版数值、怪群与支路接口见 [combat-v4.md](combat-v4.md)，上一版元素规则保留在 [combat-v3.md](combat-v3.md)。

## 地图与已实现内容

第一章包含灰烬前庭、无声回廊、遗忘圣所、熔火工坊、敲钟长阶、钟下祭坛六个主区域，通过走廊组成连续地图。入口旁的荒废墓园、圣堂与工坊之间的铸钟废仓是两处支路。已清理区域可以返回，回头不会重新刷新已完成的战斗。

- 荒废墓园的“守墓者遗物”：接近并按 `E` 取得本局技能基础伤害 +10、60 金币；进入关卡即可探索。
- 铸钟废仓的“工坊补给箱”：第三主区域领取清场祝福后可用；按 `E` 取得 2 瓶药水、最多恢复 60 生命、50 金币，药水和生命均不超过自身上限。

两个目标都要求距离不超过 2.4 米且没有地形阻挡，每局各能领取一次。它们也计入“支路搜寻”委托。`E` 不会把玩家传送过去，也不会跳过主路战斗。

可行走地形包围盒约为 136 × 121 米，实际道路是不规则区域的并集。地图布局固定，随机性主要来自敌人、出生位置、掉落与祝福选择。共享全局坐标用于角色、攻击、掉落、镜头和小地图。

- 方向攻击、闪避无敌、三元素范围技能、持续地面伤害、连锁、减速、护盾、药水与敌方飞弹。
- 低生命杂兵组成怪群，混有近战、远程、重击者与精英；具备重击、飞弹和半血增援的丧钟守卫。同时存活上限为 36 名。
- 更大范围的元素技能、实际击退与连续击杀奖励。3/6/10/16/24 连杀节点发放金币与少量对应元素冷却返还；墙体仍阻挡范围伤害和连锁。
- 区域多波战斗、清场三选一奖励、连续步行、死亡结算、最终胜利和重新开局。
- 共享地图碰撞、闪避防穿墙、贴墙滑动、通道追击、飞弹及技能遮挡。桌椅、棺木等装饰没有独立碰撞体，不能作为战斗掩体。
- 经验升级与 12 类可叠加祝福。三张卡分别展示图标、名称、真实数值和已有层数，并以铭文/躯体/元素分类；可点击或按 1/2/3 选择，祝福只在本局生效。
- 生命、经验、敌人和 Boss 血条，小地图、径向冷却、伤害数字、自绘 SVG 技能徽章与装备面板。
- 轻松、标准、困难三种难度，本地保存营地、结算战绩和设置。

暂停面板提供低、中、高三档画质、光晕与镜头震动开关、`0.5×–1.5×` 特效强度，以及音量控制。低画质关闭实时阴影与光晕后处理。设置兼容此前的本地设置记录，但不代表完成了所有设备的性能评估。

## 保存与版本边界

永久装备库、营地钱包、补给库存、营地等级和委托状态保存在本地新键 `emberfall.profile.v4`。v1 设置和战绩继续保留，测试入口使用独立键。保存失败会返回错误，不将消费或结算伪装成已完成；损坏 JSON 或不兼容存档不会被自动覆盖。

出征时另保存一份最小结算摘要，正常战斗每 15 秒及区域、支路等奖励节点尝试更新。刷新后可以在营地点“结束上次出征”，按撤退规则结算最近成功记录的收入。关闭前最后一段尚未保存的收入可能丢失。**这不是战场断点续玩**：生命、敌人位置、当前祝福和地图状态不能从关闭处继续。

没有账号、云存档或跨设备同步。清理浏览器数据、更换浏览器或访问不同站点地址/端口，可能看不到此前记录。当前也没有完整开放世界、长篇剧情、多副本网络、随机装备词条、护甲槽位、玩家交易或多人联机。

## 当前验证范围

```sh
npm test
```

本轮已记录 **45 项战斗/流程检查和 20 项营地数据检查通过**，追加回归与最终总数由 [ACCEPTANCE.md](ACCEPTANCE.md) 汇总。覆盖怪群上限、三元素清群与精英耐久、墙体遮挡、冷却返还、真实步行访问支路、补给输入、营地预算、重复消费/结算/领取、保存失败与刷新恢复。

正常属性机器人使用固定种子 `913`、标准难度，分别使用火、雷、水及其实际取得的高级武器完成六区，未改角色生命、伤害、速度或敌人数。机器人能精确读取敌人坐标与预警，并即时选择祝福、喝药和闪避，**不是三次真人试玩**。结果只证明该种子和策略下流程可完成，不代表真实玩家时长、跨种子平衡或视觉体验已定稿。

v0.3 的 22 项真实 GLB 动作检查保留为此前动作模块验证。v0.4 正式构建、营地按钮、祝福选择、支路、技能、资源加载与截图证据由 [ACCEPTANCE.md](ACCEPTANCE.md) 单独记录，本文不预先宣称浏览器最终验收完成。未做跨显卡、移动端、手柄或长时间性能认证。

## 后续扩展

先根据真人试玩调整接敌距离、命中反馈、镜头、红色预警和三元素的攻防平衡。反馈最好注明区域、敌人、武器和操作；水系护盾在精确走位的机器人策略下较强，需要真实试玩进一步评估。

下一步可增加剧情、更多委托与支路线、新副本和新 Boss。现有营地商店只售两种补给，永久装备库仅六件武器；随机词条、护甲槽和大规模物品背包仍需单独设计。营地经济与掉落节奏也需要真人试玩调整。真正的战场断点存档和剧情进度另需完整状态序列化、版本迁移与恢复验证。

当前架构适合继续验证俯视动作战斗与中小型关卡。如果目标变为大世界、复杂物理、大量骨骼角色、原生客户端或多人联机，再评估 Godot、Unity、Unreal 的工具链与迁移成本。Blender/GLB 素材可作为迁移基础，但现有 JavaScript 战斗逻辑不能承诺零成本迁移。
