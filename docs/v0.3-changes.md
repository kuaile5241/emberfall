# v0.3 变更记录

本版沿用 v0.2 的六区连续地下城和两处支路，新增三元素武器、装备切换与临时战斗状态。本文依据 `src/content.js`、`src/game.js`、UI 与 [combat-v3.md](combat-v3.md) 的当前实现编写；构建、浏览器和资源整合的最终证据由 [ACCEPTANCE.md](ACCEPTANCE.md) 单独记录。

## 玩家可用内容

- 主菜单选择火焰骑士、雷刃游侠或潮汐使，决定初始装备。每局实际拥有三把基础武器，开局选择不限制后续换装。
- 按 `B` 查看六件武器、拥有状态、当前实际属性与祝福；已拥有武器可直接装备。属性计算包含本局祝福和临时增益。
- 按 `Tab` 循环火 → 雷 → 水，优先该元素已拥有的高级武器。同元素基础/高级武器在 `B` 面板中选择。
- 鼠标左键或 `J` 普攻，鼠标右键或 `K` 使用当前武器范围技能。普通攻击仍是近身方向攻击；连击第三段 +15% 伤害，停手超过 1.6 秒或换装后重置。
- 首区领取清场祝福时，保证取得领取时所持元素的高级武器；精英优先掉落尚未拥有的高级武器。装备靠近自动拾取，取得后不自动装备。

| 职业 | 初始装备 / 技能 | 高级装备 / 技能 | 差异 |
| --- | --- | --- | --- |
| 火焰骑士 | 余烬长剑 / 焚野 | 烬王重剑 / 炼狱环 | 火场持续伤害与短时增伤；高级版扩大范围、延长火场并提高增伤，普通攻击较慢 |
| 雷刃游侠 | 引雷长枪 / 环链雷击 | 风暴战戟 / 风暴回响 | 连锁雷击与短时攻速；高级版连锁目标更多，并追加一次延迟雷震 |
| 潮汐使 | 涌泉法杖 / 潮汐环 | 深潮权杖 / 深潮领域 | 水域减速与有限护盾；高级版追加水域伤害、更强减速及更厚护盾 |

## 状态与组合规则

`余火昂扬` 提高后续普攻和技能爆发伤害；`疾电` 提高后续攻速；`潮汐护盾` 吸收经过护甲减免后的伤害，超出盾量才扣生命。不同元素增益可以共存，换装不会移除它们。同名增益刷新持续时间与强度，不叠层；护盾刷新替换旧吸收池。

技能冷却分火、雷、水三份记录，未装备元素继续计时。同元素的两把武器共享冷却，换装不能重置计时。已有攻击冷却同样保留。火场等持续区域按施放时的数值结算，之后换装或获得增益不会追溯改写已经落地的效果。

火场、雷链、范围伤害和清除飞弹会检查墙体遮挡；减速实际影响敌人的移动。死亡清除区域、增益、护盾和计时，重新开局恢复三把基础武器。详见 [combat-v3.md](combat-v3.md)。

## 界面与设置

- 左上角继续保持无章节说明；常规提示集中在下方，只在必要交互时出现。
- 四个自绘 SVG 技能徽章随当前元素更新，攻击图标区分武器，技能提示说明操作与效果；保留径向冷却和按键反馈。
- 生命条旁显示剩余护盾，增益徽章显示倒计时。
- 暂停面板增加低/中/高画质、光晕与镜头震动开关、`0.5×–1.5×` 特效强度。低档不启用实时阴影与光晕后处理。原音量与静音设置保留，兼容此前设置记录。
- 快速单击普攻和短按 `J` 保留排队输入，按住仍可持续攻击。
- QA 状态加入当前装备、库存、派生属性、护盾、增益、地面区域与画面设置，供整合验收检查。

## 验证与版本边界

已记录 **33 项逻辑测试通过**，由原 16 项、14 项元素/装备测试、3 项正常属性全流程测试构成。三种元素机器人在标准难度、固定种子 `913` 下均完成六区，未提高生命、伤害、速度或减少敌人数。机器人精确读取敌人和预警，不能等同于真人试玩，也不足以证明所有种子的难度平衡。

UI 的 Node 语法、37 个静态 DOM ID、24 个 SVG 文档/渐变引用与装备数据接口检查已通过。随后已完成正式构建与浏览器整合验证，结果见 [ACCEPTANCE.md](ACCEPTANCE.md)。

v0.3 的 `src/actors.js` 已接入五种角色资源，加入上下身动画分层、走跑/后退/侧移混合、三段连击、转向阻尼和动作优先级；真实 GLB 的 22 项检查通过。新增 Mage 与三把原创元素武器 GLB 已在正式版加载并完成施法视觉检查。`blender/emberfall-v3-elemental-weapons.blend` 是三把武器的可编辑源文件；角色本体沿用 KayKit，不将武器文件冒称完整关卡或全新原创角色。

原 KayKit 角色、骨骼动作、配套武器/道具，以及 Poly Haven 贴图是第三方 CC0 素材。沿用与改装均保留原素材来源，不能称为项目完全原创模型或写实角色。v0.2 角色图、截图和素材库保留为历史；`public/assets/video/level-scene.mp4` 是 v0.1 场景视频，均不可标为 v0.3 实录。
