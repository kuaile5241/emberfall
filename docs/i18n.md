# v0.5.0 中英文

右上角 `中 / EN` 在营地、战斗与弹窗内均可切换简体中文和 English。默认简体中文，刷新后读取上次选择。

## 实现边界

- `src/i18n.js` 管理语言、插值、订阅与独立偏好键 `emberfall.locale.v1`；测试页面使用 `.qa` 后缀。无外部翻译服务或运行时联网请求。
- `src/locales/` 按营地、游戏内容、主界面分开保存英文词库，中文原文作为稳定查找键。未知词条回退中文；存储不可用时仍可在当前页面切换。
- 翻译在显示时发生。装备、祝福、区域、任务 ID 和游戏数值保持不变，不把翻译文字写入营地存档。
- 切换保留当前出征、装备、营地页、难度和人物预览画布；当前弹窗原位重绘。结算页只重绘已有结算结果，不重复结算。短暂战斗提示会清掉，后续提示使用新语言。
- 领取祝福的 200ms 动画期间暂禁语言按钮，防止重绘放开防重复领取状态。完成后自动恢复。
- 覆盖营地四页、装备及技能说明、祝福卡、BUFF、任务与区域、战斗 HUD、暂停设置、操作说明、结算、加载与存档错误提示，并同步 `html.lang`、标题及辅助标签。

## 验证（2026-10-01）

- `npm test`：90 项通过，包含 9 项语言测试与 16 项中英领奖输入回归。覆盖偏好恢复/非法值/存储失败、词条覆盖、两语切换、状态保持、领奖动画和移动恢复。
- `npm run build`：通过。保留现有 Three.js 主包超过 500 kB 的体积提示，未做额外拆包。
- 独立 QA 页面验证：营地四页与人物画布保留、困难难度保持、切回中文、刷新后仍为英文；1280×720 英文排版与资金/语言入口不重叠。
- 构建版 `http://127.0.0.1:4173/?qa=1` 验证：暂停时切换保持同一 Game 实例及完整战斗/营地快照；装备、操作、祝福英文完整；换语前后选项 ID 不变；领取后恢复 playing，实际浏览器键盘事件使角色移动约 1 米；结算页来回切换不改变营地快照。浏览器错误日志为空。
- QA 使用独立存档键和可控测试状态，没有刷新或接管用户当前的普通游戏页。截图为英文营地及祝福卡，存于 `artifacts/v0.5-qa/`。

首次使用本更新，需要在当前局结束后刷新游戏页面。语言偏好仅保存在当前浏览器与当前站点。
