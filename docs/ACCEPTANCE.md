## 当前边界

仍是一章六区连续地牢，加入两处支路及委托，没有宣称完成大型开放世界、NPC 对话剧情、第二副本或网络多人。角色沿用 KayKit 风格化模型与现有动作，本轮没有新增写实人物建模。高级武器仍复用基础造型，没有随机词条/护甲槽。

营地装备、金币、补给与委托保存在当前浏览器的本地存储；祝福与战场状态只属于本局。每 15 秒及若干奖励节点记录最低限度结算摘要；刷新可以结束旧局，不能断点续玩。没有云存档或跨设备同步。

正常玩家完整通关、长期平衡、移动端/手柄未完成验收。暂停画面仍每帧重绘（模拟时间停止），属于后续节能优化点。旧视频仍按原版本保留，本轮无新版 MP4。项目保持本地，未提交、合并、推送 Git 或发布公网。
