## 游戏概览

《余烬地牢》是一款持续开发的单人 3D 动作肉鸽。你从营地整备出征，穿过相连的地下城区域，清理怪群、选择祝福、探索物证与支路，挑战 Boss，再带着战利品回到营地。

| 内容 | 当前可体验 |
| --- | --- |
| 两章地下城 | 钟下墓城六区与两处支路；沉钟水道三区、闸轮与水压危险，分别有独立 Boss |
| 剧情与探索 | 七段主线调查、物证互动、剧情纪事与四份委托 |
| 三种元素职业 | 火焰骑士、雷刃游侠、潮汐使；六把武器决定当前职业与基础技能 |
| 技能构筑 | 六件技能遗物、六种 AOE 形态、三件独立护甲与九个天赋节点 |
| 营地成长 | 军械收藏、行囊、补给和永久强化；装备外观同步到角色身上 |
| 中英双语 | 营地、装备、剧情、战斗提示与设置可即时切换语言 |

## 开始游玩

**[打开 game.novai.ink](https://game.novai.ink/)**，推荐使用电脑键鼠。在线游玩无需安装 Node.js、下载项目或注册账号。

1. **整备**：在营地选择章节、职业和难度，在军械里点击 **装备出征**。浏览装备卡片只查看详情，不会自动换装。
2. **构筑**：进入 **构筑**，搭配同元素遗物、护甲与天赋；在行囊准备一件补给。
3. **出征**：清理怪群、领取祝福，探索支路与剧情物证，再挑战本章 Boss。
4. **回营**：结算战利品、领取主线奖励，强化装备并解锁下一章。

右上角 **中 / EN** 可即时切换语言，刷新后保留选择。营地进度保存在当前浏览器中，不跨设备同步；清除站点数据会清除进度，关闭或刷新后暂不能恢复正在进行的战场。

<details>
<summary><strong>章节推进与结算说明（含路线提示）</strong></summary>

- **钟下墓城**：清理灰烬前庭后，在墓园支路按 `E` 取得守墓者遗物；清理熔火工坊后，靠近铸钟铭印并持续按住 `E` **2.4 秒**。松手、离开或受击会中断。
- **主线解锁**：击败丧钟守卫后回营，在剧情纪事中依次领取第一章四段奖励，解锁沉钟水道。一局可以搜齐物证；未搜齐的物证可在后续出征补足。
- **沉钟水道**：躲避定点水压，清理断桥闸室后持续按住 `E` 开启闸轮。本局幽潮守望者伤害降低 **20%**；Boss 潮环的中间是安全区，环外也能避险。
- **调查结局**：完成水道并领取后三段主线奖励，可以回看纪事、重访两章。主线奖励只领一次，重复出征仍可获得普通战利品。
- **清场与祝福**：清场后按 `E` 领奖，再沿通道前进。祝福与临时 BUFF 只属于本局，已收集的调查物证在结算后保留。
- **失败与撤退**：死亡带回本局金币的 **60%**，主动撤退带回 **25%**。Boss 主线证据要求本章胜利；刷新后只能结算已记录摘要，不能恢复战场。

</details>

## 装备与技能构筑

武器决定职业与基础技能，遗物改变技能的命中方式，护甲与天赋进一步影响伤害、控制和冷却。高级军械与独立护甲都有实际穿着效果，营地与战场使用相同外观。

| 元素 | 遗物 → 技能形态 | 战斗方式 |
| --- | --- | --- |
| 火 | 地脉余烬 → **地脉焚柱** | 沿瞄准方向依次喷发；可搭配余震回响或增加柱数与范围 |
| 火 | 坠星熔核 → **坠星** | 指定落点，陨石延迟落地并留下余火 |
| 水 | 雪暴棱镜 → **白夜暴雪** | 持续落冰、叠加寒冷并冻结；可搭配碎冰或延长覆盖 |
| 水 | 逐浪石 → **奔潮** | 宽幅水浪向前推进，减速并推开敌人 |
| 雷 | 导雷线圈 → **导雷** | 在目标间依次跳跃；可搭配末端过载 |
| 雷 | 裂空棱晶 → **裂空雷枪** | 三道方向雷枪穿透，重叠命中同一目标只结算一次 |

进入 **构筑 → 元素页 → 装备遗物**。元素页用于筛选，左侧角色图标用于切换职业。遗物需要同元素武器才生效，换到其他元素时恢复该武器的基础技能。

初始拥有 **3 点天赋**，前三次胜利各增加 1 点，最多 **6 点**。每系包含一个前置与两个互斥分支，支持免费洗点。护甲、遗物与天赋在出征时固定，战场按 `B` 查看本局配置；待结算时的营地整备只影响下一局。

<details>
<summary><strong>军械、购买与搭配规则</strong></summary>

| 职业 | 基础 / 高级武器 | 基础战斗特点 |
| --- | --- | --- |
| 火焰骑士 | 余烬长剑 / 烬王重剑 | 近战斩击、灼烧与短时增伤 |
| 雷刃游侠 | 引雷长枪 / 风暴战戟 | 快速突刺、雷击与攻速提升 |
| 潮汐使 | 涌泉法杖 / 深潮权杖 | 持续水域、减速与护盾 |

- 三件基础遗物免费收藏，另三件各 **100 金币**；三件护甲各 **70 金币**。金币来自正常出征、剧情与委托，已拥有装备再次装备不扣款。
- **余烬披风**提高火系技能伤害；**冰川长袍**提高水系对减速、冻结敌人的伤害；**风暴护衣**增加雷链目标并缩短雷系冷却。
- 高级武器可通过战利品与委托奖励永久收藏。军械外观与独立护甲叠加显示，取下独立护甲后恢复原外观。
- 天赋点由全部元素共用；移除前置节点会一并移除其后续节点。并非所有天赋都对每种同元素技能生效，以游戏内说明为准。
- Boss 的暴雪冻结时长与再次冻结间隔受限；碎冰不会递归触发，回流每次施法最多返还 **1 秒**冷却。
- 特效按画质设置减少临时对象与粒子，并在换区或回营时清理。

</details>

## 本地运行

需要 **Node.js 22.12 或更新的 22.x 版本**及 npm。`main` 提供当前可游玩版本，模型、贴图与声音已包含在仓库中，无需安装 Blender。

```sh
git clone --branch main https://github.com/we1jia/emberfall.git
cd emberfall
npm ci
npm run dev
```

浏览器打开 <http://127.0.0.1:4173/>。

构建并预览：

```sh
npm run build
npm run preview
```

<details>
<summary><strong>macOS 启动器与运行须知</strong></summary>

安装依赖并完成构建后，可以双击 `开始游戏.command`，或在终端执行：

```sh
./开始游戏.command
```

启动器需要 **Python 3**。`dist/` 和 `node_modules/` 不提交到仓库，首次克隆必须先运行 `npm ci` 与 `npm run build`。

上述启动方式共用 **4173** 端口，同一时间只运行一种。保留启动终端，按 `Ctrl+C` 停止服务。不同域名或浏览器使用各自的本地存档，在线站点与本地开发进度不会自动同步。

</details>

## 开发与验证

使用 **JavaScript · Three.js · Vite**。Blender 源文件保存在 `blender/`，资产生成工具与来源另有文档说明。

```sh
npm test
npm run test:flow
npm run build
```

**v0.8 已留存的验收结果（2026-10-02）**：全量逻辑回归 **253/253**，其中流程子集 **182/182**；中英文浏览器构筑流程分别 **114/114** 与 **113/113**。这些数字对应版本验收记录，修改代码后请重新执行相应检查。

## 项目状态与后续方向

当前 **v0.8.0** 已提供两章可反复出征的内容。地图采用固定设计，剧情通过任务与纪事展示；尚未实现完整开放世界、随机装备词条与分解、云存档、联机或实体 NPC 对话与配音。

接下来计划完善战利品与元素搭配，增加分路、遭遇与后续章节，再补齐教学、存档恢复、无障碍和设备性能验证。公开试玩站点已开放，后续计划不代表功能已经交付，详见 [产品化路线](docs/product-roadmap-plan.md)。
