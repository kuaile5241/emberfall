# 余烬地牢：钟下墓城

**Emberfall · v0.8.0 · [MIT](LICENSE)**

单人 3D 动作肉鸽游戏。整备装备与补给，从营地出征，在连续的地下城中清理怪群、选择祝福、探索支路，最终挑战丧钟守卫，再将战利品带回营地。

![构筑工坊](artifacts/builds-v0.8/workshop-zh.png)

目前有两个可游玩章节：钟下墓城六区、两处支路和丧钟守卫；沉钟水道三区、闸轮、水压危险和幽潮守望者。七段原创主线串联两个副本，物证需要实际探索与互动取得。火、雷、水三种元素、六把武器、营地军械、行囊、永久强化与四份委托继续保留。职业与技能随当前武器变化。

v0.8 新增营地 **构筑工坊**：六种真正不同的技能形态、六件技能遗物、三件独立护甲与九个天赋节点。技能遗物改变命中几何和时序；护甲与天赋参与战斗加成，并有实际穿着效果。参见 [AOE / BD 官方机制调研](docs/build-research-v0.8.md)、[v0.8 验收](docs/v0.8-acceptance.md)。

v0.7 补齐“出征调查 → 回营领主线奖励 → 解锁下一章节 → 完成调查结局”的第一轮闭环。新增地图共享碰撞、导航、渲染和小地图定义；闸轮会降低本局 Boss 伤害，潮汐环有可躲入的安全内圈。旧 V4 存档直接兼容，历史装备与经济保留，不凭旧胜场虚构已调查的新物证。见 [产品化计划](docs/product-roadmap-plan.md)、[官方玩法调研](docs/product-research-v0.7.md)、[v0.7 验收](docs/v0.7-acceptance.md)。

v0.6.1 统一炭黑、深灰与暖金界面；高级装备会同步改变肩甲、腕甲与头饰。待结算时可以整备下一局职业、武器和补给，旧战利品独立保留。本版修复了职业换装、领奖后移动、选卡时暂停恢复误领奖，以及最深关卡统计问题；新增中英文浏览器全流程自动化。见 [换装与界面记录](docs/v0.6.1-fixes.md)、[流程测试记录](docs/flow-automation.md)。

这是持续开发中的游戏，尚未具备完整开放世界、随机装备词条与分解、云存档或联机。剧情以纪事和任务展示，暂没有实体 NPC 对话或配音。后续按构筑、路线、内容、发行质量逐阶段交付。v0.4.1 修复了领取祝福后无法移动的问题。

## 启动

需要 **Node.js 22.12 或更新的 22.x 版本**及 npm。推荐使用电脑键鼠游玩，运行时无需账号或后端服务。

当前 v0.8.0 由 `main` 主分支提供。以下命令获取当前可游玩版本：

```sh
git clone https://github.com/we1jia/emberfall.git
cd emberfall
npm ci
npm run dev
```

浏览器打开 <http://127.0.0.1:4173/>。GitHub 仓库已公开，浏览与克隆无需登录；登录 GitHub 后即可 Fork。

预览构建版：

```sh
npm run build
npm run preview
```

macOS 也可以在完成 `npm ci` 和 `npm run build` 后，双击 `开始游戏.command`；这种启动方式需要 Python 3。终端启动方式为：

```sh
./开始游戏.command
```

`dist/` 与 `node_modules/` 不提交到仓库，首次克隆必须安装依赖；双击启动器前必须先构建。以上启动方式共用 4173 端口，同一时间只运行一种。保留启动终端，按 `Ctrl+C` 停止服务。

营地进度保存在当前浏览器的本地存储中，不跨浏览器或设备同步。清除站点数据会清除营地进度；战斗中的局内进度暂不支持关闭后恢复。

## 开始游玩

1. 在营地选择章节、职业和难度；在军械中查看武器，再点 **装备出征**。卡片只查看详情，不自动换装。
2. 点当前主线或委托页查看 **剧情纪事**。支线委托可以独立接受；行囊中可购买补给，选择一件在出征时消耗。
3. 第一章清理灰烬前庭，进入墓园支路按 `E` 取守墓者遗物；清理熔火工坊后，靠近 **铸钟铭印并持续按住 E 2.4 秒**。松手、离开或受击会中断。
4. 清场后按 `E` 领取祝福，再沿通道进入下一区域。祝福和临时 BUFF 只属于本局；实际收集的剧情物证会在结算时留存。
5. 击败丧钟守卫后回营，在剧情纪事中依次领取第一章四段主线奖励，解锁 **沉钟水道**。一局可以搜齐物证，无须为了逐段领奖重复打四遍；未搜齐也可下一局补足。
6. 在水道闪避定点水压，清理断桥闸室，靠近闸轮持续按住 `E`。开启后幽潮守望者伤害降低 20%；Boss 潮环的中间是安全区，环外也能避险。
7. 完成水道后领取后三段剧情奖励，可以回看纪事和重访两个章节。主线奖励只领一次，回刷继续获得普通战利品。

死亡带回 60% 本局金币，主动撤退带回 25%。已结算的调查物证仍保留；Boss 主线证据要求本章胜利。刷新后只能结算已记录摘要，暂不能恢复战场。

## 元素与换装

| 职业 | 基础 / 高级军械 | 战斗特点 |
| --- | --- | --- |
| 火焰骑士 | 余烬长剑 / 烬王重剑 | 近战斩击、爆发火场、持续灼烧与短时增伤 |
| 雷刃游侠 | 引雷长枪 / 风暴战戟 | 快速突刺、范围雷击、远处连锁与攻速提升 |
| 潮汐使 | 涌泉法杖 / 深潮权杖 | 水域持续冲击、减速与护盾 |

高级军械会联动真实三维护甲、头饰和武器，营地与战场共用外观。军械穿着和独立护甲叠加显示；原护甲在取下独立装备后恢复。暂不提供随机词条。高级武器可通过战利品和委托奖励永久收藏。

## 技能形态、装备与天赋

营地左侧点 **构筑** → 选择元素页 → 点击 **装备** 技能遗物。查看元素页只筛选内容；左侧角色图标才切换职业。遗物需要同元素武器才生效，换到其他元素时恢复该武器的原生技能。旧存档默认不装备新遗物，原六把武器技能保留。

| 元素 | 技能遗物 → 形态 | 命中方式与搭配 |
| --- | --- | --- |
| 火 | 地脉余烬 → 地脉焚柱 | 沿瞄准方向分次喷发；余震追加回响，或地脉增压增加柱数与范围 |
| 火 | 坠星熔核 → 坠星 | 瞄准落点，延迟陨石后留余火；余震追加一次回响 |
| 水 | 雪暴棱镜 → 白夜暴雪 | 瞄准落点持续下雪，叠寒冻结；碎冰引爆冻结敌人，或白夜延长覆盖但增加冷却 |
| 水 | 逐浪石 → 奔潮 | 宽幅水浪向前扫过，每名敌人一次命中、推开、减速 |
| 雷 | 导雷线圈 → 导雷 | 指向首个敌人后逐次跳跃；过载末端爆炸，或回流击杀返还有限冷却 |
| 雷 | 裂空棱晶 → 裂空雷枪 | 三道方向雷枪穿透；命中重叠目标仍只结算一次 |

三件基础遗物免费收藏；另三件各 100 金币。护甲各 70 金币：余烬披风提高火系技能伤害，冰川长袍提高水系对减速/冻结敌人的伤害，风暴护衣增加雷链目标并缩短雷系冷却。金币来自正常出征结算、剧情和委托；装备不重复扣款。

初始 3 点天赋，前三次胜利各增加 1 点，最多 6 点。每系有一个前置和两个互斥分支，免费洗点；移除前置会同时移除后续节点。天赋点在所有元素间共用。护甲、遗物和天赋在出征时固定；待结算时的整备只影响下一局，战场 `B` 显示本局配装。

Boss 的暴雪冻结时间与再次冻结间隔受限；碎冰不能递归产生碎冰；回流每次施法最多返还 1 秒。特效按质量设置减少雪片、临时对象和共享粒子，并在换房或回营时清理。

## 语言

点击右上角 **中 / EN**，即可在简体中文和 English 之间即时切换。营地、装备、技能、任务、祝福、战斗提示和设置均支持双语，刷新后保留语言偏好。切换不重开战斗，也不会修改营地存档；默认简体中文。

## 圆润角色与营地整备

v0.6 为三种职业重做圆润几何与材质，营地和战斗共用真实模型与原有骨骼动作。营地采用侧栏导航、暖灯角色台和出征整备区；军械提供元素筛选、专属技能与真实出征属性对比，行囊提供库存、携带槽、购买、取下和永久强化路线。

[本版改进与验证](docs/v0.6-changes.md)、[圆润建模源文件说明](docs/models-v6.md)、[可爱素材与制作教程](docs/cute-art-guide-v6.md)。

v0.7 保留的原流程证据：中文 **30/30**、英文 **29/29** 浏览器检查通过，均完成六区、293 击杀和最终 Boss，并验证领奖后移动、结算、委托领取、营地强化、再次出征与回营。流程页每次生成独立测试存档，保留普通游戏进度；右上角显示 PASSED/FAILED，完整结果可读取 `window.__emberfallFlow`。

构筑流程使用 `window.__emberfallBuildFlow`，实际点击新装备与天赋，通过正常输入验证六种形态、真实特效与回营整备。Node 矩阵另覆盖六形态 × 两章，共 12 次正常属性胜利；具体证据见 [v0.8 验收](docs/v0.8-acceptance.md)。

新增两章流程使用 `window.__emberfallCampaignFlow`，实际点击章节、剧情领奖与换装；长按机关经过真实 `main.js` 键盘监听及动画帧，不仅直接传 `interact` 给模拟。中英文均已完成六区 + 三区、所有七段领奖和水道机制检查；完整报告、截图及具体计数见 [v0.7 验收](docs/v0.7-acceptance.md)。

战斗由名义 30Hz 输入机器人驱动，机器人知道敌人与预警位置；持续机关操作额外经过浏览器动画帧。这些结果验证功能和路径，不能替代真人难度、跨设备或长期性能测试。此前证据保留在 [流程自动化验收](docs/flow-automation.md)。

游戏使用 JavaScript、Three.js 与 Vite。模型与贴图已随仓库提供，游玩无需安装 Blender。`blender/` 保留建模源文件；资产生成工具的环境要求见对应文档。

| 目录 | 内容 |
| --- | --- |
| `src/` | 战斗、地图、营地、动画与界面 |
| `public/` | 运行时模型、贴图、图标、声音与素材许可 |
| `blender/` | Blender 源文件与建模脚本 |
| `tests/` | 战斗、营地、交互与回归测试 |
| `tools/` | 本地启动及资产生成、检查工具 |
| `docs/` | 玩法、设计、素材来源及验收记录 |
| `artifacts/` | 版本截图与验证记录 |

采用 Gitflow：`main` 提供当前可游玩版本，`develop` 用于集成，功能在独立分支开发。本项目要求提交推送时，默认包含测试、README 更新、功能集成、主分支同步与远端核验；指定分支或限制合并时遵循当次要求。完整约定见 [AGENTS.md](AGENTS.md)。
